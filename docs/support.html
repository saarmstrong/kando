Support

Need help? Reasonable. Software is just mistakes with icons.

Before asking for help

  • Make sure Reminders access is enabled for the app.
  • Confirm Apple Reminders/iCloud sync is working in Apple’s own Reminders app.
  • Try quitting and reopening the app.
  • Try pull-to-refresh on the board.

Common notes

  • Kando stores tasks as native Apple Reminders.
  • Sync depends on Apple Reminders and your iCloud/account settings.
  • Matrix assignments are local app settings, not separate Reminders lists.
  • Completed tasks can be hidden from Settings.

Reporting an issue

If this repo is public, the best support path is to open a GitHub issue. Include:

  • Device and OS version.
  • Whether this is iOS or macOS.
  • What you expected to happen.
  • What actually happened, in all its disappointing glory.
  • Screenshots if useful.

Guarantee level

This is a free, minimal app made primarily for personal use. Support is best-effort. There is no warranty, service-level agreement, heroic pager rotation, or enterprise account manager named Brent.
